# じゃんけんぽんゲーム 仕様書

## 概要

URLを共有して、複数人でじゃんけんができるWebアプリ。

しあい作成者がしあい名と参加人数を決め、参加者は共有されたURLから名前と手を送信する。全員が送信すると結果が表示される。

しあいの有効期限は作成から1週間とする。

## ユーザー

### しあい作成者

しあいを作成し、参加URLを参加者に共有する人。

### 参加者

共有されたURLからじゃんけんに参加する人。

## 画面一覧

1. スタート画面
2. しあい作成画面
3. 作成完了・URL共有画面
4. 参加者のじゃんけん画面
5. 送信完了・待機画面
6. 結果画面
7. 期限切れ画面

## 基本ルール

- 参加人数は2〜10人とする。
- しあいの有効期限は作成から1週間とする。
- 期限切れ後は参加できない。
- 参加者は名前を入力する。
- 参加者は「ぐー」「ちょき」「ぱー」から1つ選ぶ。
- 全員が送信したら結果を表示する。
- 参加人数の上限に達している場合、それ以上は送信できない。

## 勝敗ルール

- ぐーはちょきに勝つ。
- ちょきはぱーに勝つ。
- ぱーはぐーに勝つ。
- 全員が同じ手なら引き分け。
- 3種類すべての手が出たら引き分け。
- 勝ち手を出した参加者を勝者として表示する。

## 期限ルール

- しあい作成時に `expires_at` を保存する。
- `expires_at` は作成日時から1週間後とする。
- 期限は画面上では具体的な日時で表示する。
- 期限切れ後に参加URLへアクセスした場合、期限切れ画面を表示する。
- 期限切れ後は新しい投稿を受け付けない。

## データ

### games

しあいの情報を保存する。

| 項目 | 内容 |
|---|---|
| id | しあいID |
| name | しあい名 |
| player_count | 参加人数 |
| expires_at | 有効期限 |
| created_at | 作成日時 |

### game_results

参加者が送信した手を保存する。

| 項目 | 内容 |
|---|---|
| id | 結果ID |
| game_id | どのしあいの結果か |
| player_name | 参加者名 |
| weapon | 出した手 |
| created_at | 送信日時 |

## 手の保存値

DBには分かりやすい文字列で保存する。

| 表示 | 保存値 |
|---|---|
| ぐー | rock |
| ちょき | scissors |
| ぱー | paper |

## エラーの考え方

エラーは、ユーザーが次に何をすればよいか分かる文言にする。

例:

- 名前を入力してください。
- 手を選んでください。
- このしあいは期限切れです。
- 参加人数の上限に達しています。
