# Figma Make 用プロンプト

じゃんけんぽんゲームのスマホ向けWebアプリUIを作成してください。

## アプリ概要

URLを共有して複数人でじゃんけんできるWebアプリです。

しあい作成者がしあい名と参加人数を決め、参加者は共有されたURLから名前と手を送信します。全員が送信すると結果が表示されます。

しあいの有効期限は作成から1週間です。

## デザイン方針

- スマホで使いやすいUIにする。
- 友達同士で気軽に使える雰囲気にする。
- 子どもっぽすぎず、やわらかく親しみやすい見た目にする。
- ボタンは大きく押しやすくする。
- 余白をしっかり取り、情報を読みやすくする。
- 期限、参加人数、現在の状態が分かりやすいようにする。
- ぐー・ちょき・ぱーは大きな選択ボタンとして表示する。
- エラー文は入力欄の近くに表示する。

## 作成してほしい画面

1. スタート画面
2. しあい作成画面
3. 作成完了・URL共有画面
4. 参加者のじゃんけん画面
5. 送信完了・待機画面
6. 結果画面
7. 期限切れ画面

## 各画面の内容

### 1. スタート画面

- アプリ名
- 短い説明文
- 使い方の4ステップ
- 「作成したしあいは1週間有効です」という説明
- しあいを作るボタン

### 2. しあい作成画面

- アプリ名
- しあい名入力欄
- 参加人数選択
- 「作成から1週間有効」の説明
- しあいを作るボタン
- 入力エラー表示

### 3. 作成完了・URL共有画面

- 作成完了メッセージ
- しあい名
- 参加人数
- 参加URL
- 結果URL
- 有効期限
- 参加URLコピーボタン
- 結果URLコピーボタン
- コピー成功メッセージ

### 4. 参加者のじゃんけん画面

- しあい名
- 有効期限
- 現在の参加状況
- 名前入力欄
- ぐー・ちょき・ぱーの大きな選択ボタン
- ぽん！ボタン
- 入力エラー表示

### 5. 送信完了・待機画面

- 送信完了メッセージ
- 「ほかの参加者を待っています」という説明
- 現在の参加人数
- 必要な参加人数
- 有効期限
- 結果を確認するボタン

### 6. 結果画面

- 結果タイトル
- 勝者
- 全員の名前と手
- 勝ち / 負け / 引き分けの表示
- 有効期限
- 新しいしあいを作るボタン

### 7. 期限切れ画面

- 期限切れメッセージ
- しあい名
- 有効期限
- 新しいしあいを作る案内
- 新しいしあいを作るボタン

## フォーム・エラー状態

以下の状態もデザインしてください。

- 通常状態
- 入力エラー状態
- 送信中状態
- コピー成功状態
- 参加人数の上限に達している状態
- 期限切れ状態
