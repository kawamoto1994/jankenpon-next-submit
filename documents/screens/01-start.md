# スタート画面

## 目的

ユーザーにアプリの概要を伝え、しあい作成画面へ進んでもらう。

## 表示する情報

- アプリ名
- 短い説明文
- 使い方の簡単な流れ（しあいを作る / URLを共有する / みんなが手を出す / 結果を見る）
- しあいの有効期限
- しあい作成画面へのボタン

## 表示例

```text
じゃんけんぽん

URLを共有して、みんなでじゃんけんできるゲームです。
しあいを作って、友だちにURLを送るだけ。

作成したしあいは1週間有効です。

遊び方

1. しあいを作る
2. URLを共有する
3. みんなが手を出す
4. 結果を見る

[ しあいを作る > ]
```

## フォーム項目

なし。

## ボタン

| ラベル | 動作 |
|---|---|
| しあいを作る | しあい作成画面へ移動する |

## バリデーション

なし。

## 状態

- 通常

## 遷移

- 「しあいを作る」を押す: しあい作成画面へ
