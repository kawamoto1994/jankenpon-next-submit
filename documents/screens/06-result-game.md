# 結果画面

## 目的

全員の手と勝敗を表示する。

## 表示する情報

- しあい名
- 進行ステップ（しあいを作る / URLを共有する / みんなが手を出す / 結果を見る）
  ※現在の画面に対応するステップには `aria-current="step"` を付ける。
- 結果
- 勝者
- 全員の名前
- 全員の手
- 勝ち / 負け / 引き分け
- 有効期限

## 表示例

```text
じゃんけん結果

結果: たろうさんの勝ち

たろう: ぐー / 勝ち
はなこ: ちょき / 負け

有効期限: 2026年7月12日 23:59まで

[ 新しいしあいを作る ]
```

## フォーム項目

なし。

## ボタン

| ラベル | 動作 |
|---|---|
| 新しいしあいを作る | しあい作成画面へ移動する |

## バリデーション

なし。

## 状態

- 結果表示
- まだ全員が送信していない
- 引き分け
- 期限切れ

## 表示ルール

- 全員が送信済みの場合、結果を表示する。
- まだ全員が送信していない場合、待機中の表示にする。
- 全員が同じ手の場合は引き分け。
- 3種類すべての手が出た場合は引き分け。
- 勝ち手を出した参加者を勝者として表示する。

## 遷移

- 「新しいしあいを作る」を押す: しあい作成画面へ
