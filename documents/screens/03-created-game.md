# 作成完了・URL共有画面

## 目的

作成したしあいの参加URLと結果URLを共有できるようにする。

## 表示する情報

- 作成完了メッセージ
- 進行ステップ（しあいを作る / URLを共有する / みんなが手を出す / 結果を見る）
  ※現在の画面に対応するステップには `aria-current="step"` を付ける。
- しあい名
- 参加人数
- 参加URL
- 結果URL
- 有効期限

## 表示例

```text
しあいを作りました

しあい名: 週末じゃんけん
参加人数: 4人
有効期限: 2026年7月12日 23:59まで

参加URL
https://example.com/game/xxxx
[ 参加URLをコピー ]

結果URL
https://example.com/result/xxxx
[ 結果URLをコピー ]
```

## フォーム項目

なし。

## ボタン

| ラベル | 動作 |
|---|---|
| 参加URLをコピー | 参加URLをクリップボードにコピーする |
| 結果URLをコピー | 結果URLをクリップボードにコピーする |
| 新しいしあいを作る | しあい作成画面へ移動する |

## バリデーション

なし。

## 状態

- 通常
- コピー成功
- コピー失敗

## エラー・メッセージ

- コピー成功: `コピーしました。`
- コピー失敗: `コピーできませんでした。URLを選択してコピーしてください。`

## 遷移

- 参加URLへアクセス: 参加者のじゃんけん画面へ
- 結果URLへアクセス: 結果画面へ
- 「新しいしあいを作る」を押す: しあい作成画面へ
